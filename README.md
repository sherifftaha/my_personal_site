# my_personal_site

Personal site for Sherif Taha, Odoo Functional Consultant & Developer.

Built with React, Vite and Tailwind CSS. The contact form uses EmailJS.

## Editing content

All text lives in `src/data.js`. To show the LinkedIn link and the "Download CV"
buttons, fill in `profile.linkedin` and `profile.cv` there (put the CV file in
`public/` and use a path such as `/Sherif-Taha-CV.pdf`).

## Commands

- `npm install`
- `npm run dev` to work locally
- `npm run build` to build for production
